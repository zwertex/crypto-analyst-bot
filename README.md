# crypto-analyst-bot

Telegram-бот для подробного теханализа крипты с готовым планом сделки (LONG/SHORT/NEUTRAL).

## Что внутри

- **aiogram 3** — кнопочный UI: жмёшь «🔍 Сканировать монету» → вводишь тикер → получаешь карточку с сигналом.
- **Binance public API** — спот-свечи + 24h-тикер + funding rate (без API-ключа, ничего платить не нужно).
- **Технический анализ** — RSI(14), MACD(12/26/9), EMA(20/50/200), Bollinger Bands(20, 2σ), ATR(14), объёмы, поддержки/сопротивления.
- **Мульти-таймфрейм**: 1h × 1, 4h × 2, 1d × 3 — приоритет старшим ТФ.
- **Готовый план**: вход (текущая цена), стоп-лосс (1.5 × ATR на 4h), TP1 / TP2 (1.5R / 3R), risk/reward.
- **Избранное** — до 25 монет на пользователя, in-memory (per-process).
- **Allow-list** опционально через `ALLOWED_USER_IDS` — если хочешь приватного бота.

## Команды и кнопки

```
/start  /menu  /scan  /help
```

В UI всё через инлайн-кнопки: меню → Сканировать → ввод тикера → карточка с сигналом, кнопками «🔄 Обновить» и «☆ В избранное».

## Принимаемые форматы тикера

`BTC`, `btc`, `BTCUSDT`, `BTC/USDT`, `eth-usdt`, `solusdc` — всё нормализуется в реальный спот-символ Binance. Если нет пары `…USDT`, перебираются `USDC`, `BUSD`, `BTC`, `ETH`. Несуществующие тикеры → понятная ошибка.

## Запуск локально

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

cp .env.example .env
# открой .env и впиши BOT_TOKEN от @BotFather

python -m bot.main
```

## Как читать сигнал

🟢 **LONG** — индикаторы согласованно показывают рост.
🔴 **SHORT** — индикаторы согласованно показывают падение.
⚪ **NEUTRAL** — рынок не определился.

**Уверенность** считается как нормализованная сумма голосов индикаторов с учётом весов таймфреймов. План сделки появляется только для LONG/SHORT.

## Логика сигнала (кратко)

Каждый индикатор на каждом ТФ даёт ограниченный голос в `[-1, +1]`:

| Индикатор          | Бычий вклад                          | Медвежий вклад                       |
| ------------------ | ------------------------------------ | ------------------------------------ |
| RSI                | `<30` сильно, `<45` слабо            | `>70` сильно, `>55` слабо            |
| EMA50 / EMA200     | цена > EMA50 > EMA200                | цена < EMA50 < EMA200                |
| MACD               | MACD > сигнальной и hist > 0         | MACD < сигнальной и hist < 0         |
| Bollinger Bands    | цена у нижней BB                     | цена у верхней BB                    |
| Объём (× 1.5+ avg) | усиливает существующий бычий бал     | усиливает существующий медвежий бал  |

Голоса всех ТФ суммируются с весами `1h:1, 4h:2, 1d:3`, нормируются в `[-1, 1]`, порог сигнала — `±0.25`.

## Disclaimer

Бот считает _технические_ вероятности. Это не финансовая рекомендация. Управляй риском, не рискуй больше 1–2% депозита на сделку.
